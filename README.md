# Live Weather Travel App

Plan trips with current weather so you can decide when and where to go.

## About

This repository will hold the Live Weather Travel App: destination search, live weather for travel dates, and trip-planning helpers.

## Getting started

Project files and setup steps will land here as the app is built. Clone the repo to start:

```bash
git clone https://github.com/Danzag88/Live_Weather_Travel_App.git
cd Live_Weather_Travel_App
```

Do not commit API keys or `.env` files. Use a local env file and keep secrets out of git.
